# CS330_Kitty-Collision

This project was created for an assignment in my Computer Graphics and Visualization university course to practice what we've learned about collisions in OpenGL. It contains two folders. One was originally provided by the university as the starter code, and the other contains my modifications where I completed the assignment and implemented the idea I wanted to bring to life.

The idea I had for this assignment excited me and I spent a little too much time on it, I must say, spending way more time than I think was required, haha. I made all the textures by myself and turned it into a cute, interactive little scene/mini game. So, I wanted to upload this as a memorable little project.
